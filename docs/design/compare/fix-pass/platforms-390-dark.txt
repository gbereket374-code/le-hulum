DEVELOPER GUIDE
Add Ethiopian Sign Language in one line

Load the module once. Use <db-player> for video lessons and <db-sign-pin> for text pages. Both work without a framework, and the player falls back to a normal video if our server can’t be reached.

lesson.html
Copy code
<script type="module" src="https://le-hulum.onrender.com/module/db-player.js"></script><db-player src="lesson.mp4" captions="lesson.am.vtt,lesson.en.vtt"
  api="https://le-hulum.onrender.com/api/v1" lesson-id="demo"></db-player><db-sign-pin api="https://le-hulum.onrender.com/api/v1" lang="am"></db-sign-pin>
HOST = https://le-hulum.onrender.com

Install guide
1
Add the script tag

Paste the module script once in your page template.

2
Wrap your lesson video

Replace <video> with <db-player> and point captions at your Amharic and English .vtt files.

3
Turn on the sign pin for text

Add <db-sign-pin> to article pages. Learners get the Sign button on every block.

Reference
Attributes <db-player>
Attribute	What it does	Example
src	Lesson video file	lesson.mp4
captions	Comma-separated caption files	lesson.am.vtt,lesson.en.vtt
sign	Recorded interpreter track (optional)	lesson.sign.vtt
glossary	Words in this lesson	glossary.json
api	LE HULUM API base URL	{{ host }}/api/v1
lesson-id	Lesson identifier for feedback	demo
lang	Default caption language	am | en
theme	Player theme	light | dark | contrast
Events
progress
Fires as the learner moves through lines: { line, time, signed }.
complete
Fires when the lesson ends: { lessonId, understood }.
API endpoints
POST
/sign/translate

/sign/lesson

/lexicon

/glossary
