Noto Sans Ethiopic for all Ge'ez text, auto-fallback in every stack. Lexend replaces body Latin in dyslexia mode. JetBrains Mono for gloss, code and numbers.

Ethiopic rules

  • Never uppercase or letter-space Ge'ez (enforced by :lang(am)).
  • Line height +0.2 over Latin (body 1.7–1.8).
  • Body never below 16 px; captions 18–32 px.
  • Gloss is not uppercased for Amharic input.
