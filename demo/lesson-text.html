Python: Your first variable ፓይተን፡ የመጀመሪያ ተለዋዋጭዎ

A text lesson. There is no video. Open My settings, or use the sign pin, and choose a sentence.የጽሑፍ ትምህርት። ቪዲዮ የለም። ዓረፍተ ነገር ለመምረጥ የምልክት ፒኑን ይጠቀሙ።

ሰላም፣ እንኳን ደህና መጣችሁ።

በዚህ ትምህርት ስለ ተለዋዋጮች እንማራለን።

ተለዋዋጭ መረጃን የሚያስቀምጥ ሳጥን ነው።

መጀመሪያ የኮድ ኤዲተራችሁን ክፈቱ።

አሁን ይህን መስመር ጻፉ።

name = "Abebe"

እንደምታዩት፣ የተለዋዋጩ ስም "name" ነው።

እሴቱ "አበበ" ነው።

ቀጥሎ ተለዋዋጩን በስክሪን ላይ እናሳያለን።

print(name)

ኮዱን አስኪዱት።

ስክሪኑን ተመልከቱ። ኮምፒውተሩ "አበበ" ያሳያል።

ስህተት ካያችሁ፣ አጻጻፋችሁን አረጋግጡ።

ጥሩ ሥራ! የመጀመሪያ ተለዋዋጫችሁን ፈጠራችሁ።

በሚቀጥለው ትምህርት ስለ ድግግሞሽ (loop) እንማራለን።

አመሰግናለሁ። በሚቀጥለው እንገናኝ።

English

Hello, and welcome.

In this lesson, we will learn about variables.

A variable is a box that stores data.

First, open your code editor.

Now, type this line.

name = "Abebe"

As you can see, the variable name is "name".

The value is "Abebe".

Next, we show the variable on the screen.

print(name)

Run the code.

Look at the screen. The computer shows "Abebe".

If you see an error, check your spelling.

Good job! You created your first variable.

In the next lesson, we will learn about loops.

Thank you. See you next time.
